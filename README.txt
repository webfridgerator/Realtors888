REALTORS 888 — Static Website Starter
====================================

This is a static HTML/CSS/JavaScript starter package for realtors888.com.
It is designed for developer Salman to upload and customise.

FOLDER STRUCTURE
----------------
index.html
services.html
property-clarity.html
interiors.html
property-care.html
properties.html
about.html
contact.html
privacy.html
terms.html
assets/
  css/style.css
  js/main.js
  images/ (local SVG illustrations used by the pages)

IMPORTANT BEFORE PUBLISHING
---------------------------
1. Replace the sample contact details and placeholder social links in contact.html.
2. Add the final logo if one is available. Current wordmark is text-based.
3. The enquiry form is a front-end demo only. It does NOT send/store submissions.
   Connect it to a backend, form service, CRM, or WhatsApp flow before launch.
4. All service descriptions are proposed copy. Keep only services you can deliver.
5. Do not imply government affiliation, official file tracking, legal certification,
   guaranteed approvals, or that partner services are performed by REALTORS 888 staff.
6. Review privacy policy, terms, service pricing, RERA applicability, and local legal
   requirements with the appropriate professional before publishing.
7. SVG artwork is locally included so the site has visual assets without relying on
   external image URLs. Replace with licensed project/partner photographs as needed.

HOW TO PREVIEW
--------------
Open index.html in a browser. No build tools or server are required.
The mobile navigation and demo enquiry form use vanilla JavaScript.
